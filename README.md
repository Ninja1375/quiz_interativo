# 🎯 Quiz Interativo com JavaScript  

Um quiz interativo e responsivo para testar conhecimentos em **desenvolvimento web**.  
Projeto construído com **HTML, CSS e JavaScript puro**, com design moderno e animações.  

---

## ✨ Funcionalidades  

- ✅ 3 questões de múltipla escolha  
- ⏱️ Timer regressivo por questão (10s)  
- 📱 Design totalmente responsivo  
- 🎨 Estilo moderno com animações CSS  
- 🎉 Tela de pontuação com feedback personalizado  

---

## 🛠️ Tecnologias utilizadas  

- **HTML5** → Estrutura da aplicação  
- **CSS3** → Estilização e responsividade (inclui suporte a dark mode e animações)  
- **JavaScript (ES6+)** → Lógica do quiz (timer, pontuação, eventos, acessibilidade)
